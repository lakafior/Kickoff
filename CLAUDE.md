# Kickoff (Safari Web Extension) — read first

Kick.com chat helpers (keep screen awake, SF font, popout layout, deleted messages,
link previews, ad/tracker blocking), shipped as a Safari Web Extension inside a
macOS + iOS/iPadOS container app for the App Store. Formerly "Kick Awake", built with
Safari's "describe extension" feature; now a regular Xcode project.

## Layout
- `Kickoff.xcodeproj` — schemes `Kickoff (macOS)` and `Kickoff (iOS)`.
- `Shared (Extension)/Resources/` — **the extension itself** (manifest.json,
  background.js, content.js, page-hook.js, kickoff.css, images/). Edit code here.
- `Shared (App)/` — container app UI (Main.html, ViewController.swift) and Assets.
- `iOS (App)`, `macOS (App)`, `iOS (Extension)`, `macOS (Extension)` — per-platform
  plists/storyboards generated by `safari-web-extension-packager`.

## Conventions
- Bundle IDs: app `net.smigi.Kickoff`, extension `net.smigi.Kickoff.Extension`
  (also hard-coded in `Shared (App)/ViewController.swift`).
- Internal prefixes: storage/message keys `kickoff…` / `kickoff:…`; DOM attributes
  and CSS classes `data-ka-*` / `.ka-*`.
- Versioning: bump `MARKETING_VERSION` / `CURRENT_PROJECT_VERSION` in Xcode for
  releases; keep `manifest.json` `version` in step with `MARKETING_VERSION`.

## Build
```
xcodebuild -project Kickoff.xcodeproj -scheme "Kickoff (macOS)" build
xcodebuild -project Kickoff.xcodeproj -scheme "Kickoff (iOS)" -destination 'generic/platform=iOS Simulator' build
```
To test unsigned builds on macOS, enable Safari ▸ Develop ▸ Allow Unsigned Extensions.
